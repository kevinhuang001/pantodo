## 毎日を、少し静かに

気になることはタスクリストへ。確保したい時間はタイムテーブルへ。実際に取り組んだ時間はタイマーで記録。Pantodo はこれらを柔らかなすりガラスの画面にまとめます。アカウント登録は不要です。

- **すぐに記録。** タスク名と説明を入力し、必要に応じてプロジェクトやタグを追加。
- **無理なく予定を作成。** 開始時刻と所要時間から終了時刻を自動計算。締切は別に設定できます。
- **必要なものを表示。** フィルター付きパネルを組み合わせ、リストやギャラリーを縦または列に配置。
- **ひとつのことに集中。** 作業を開始し、休憩時には一時停止。集中画面で作業を続けられます。
- **データは自分の手元に。** ローカル保存が基本。自分の WebDAV サーバーで同期も可能。
- **好みの環境で。** macOS、Windows、Linux、日本語・英語・簡体中国語、ライト／ダークテーマと8色のアクセント。

## アイデアから、今日の予定へ

### まずは書き留める

ひとつの入力カードと小さな紙のキャラクター。説明を添え、予定、締切、プロジェクトやタグは必要なときだけ開きます。

![シンプルなタスク作成画面](docs/images/create.jpg)

### タスクの時間を決める

開始日時と予定の長さを選ぶと、日付をまたぐ場合も終了時刻を自動計算します。カスタムボタンで時間と分を入力できます。予定の長さと実際の集中時間は別に表示します。締切は予定から独立し、タイムテーブルではアクセント色の旗付きラベルで表示。日・週・月を切り替え、ピンチ操作やスライダーで時間軸を拡大できます。

![開始時刻と所要時間から終了時刻を計算](docs/images/schedule.jpg)

![カスタムボタンで時間と分を入力](docs/images/custom-duration.jpg)

### 自分だけのワークスペース

ビューを作成し、プロジェクト、タグ、状態、日付、テキストで絞り込むパネルを追加。各タスクは名前と説明だけを表示し、クリックすると詳細を編集できます。件数が多いパネルは内部でスクロールします。

各パネルはリスト／ギャラリーを選択でき、ドラッグハンドルで並べ替えられます。列数はビュー設定で変更します。

![リストとギャラリーを組み合わせたパネル](docs/images/views.jpg)

### 取り組んだ時間を振り返る

「今日」や「すべてのタスク」からタイマーを開始。短いカウントダウンの後に集中画面が開き、サイドバーも使えます。一時停止、再開、保存に対応。時間統計では日別合計、プロジェクト・タグ別の内訳、手動記録、CSV エクスポートを利用できます。

![実際の作業時間を統計で確認](docs/images/statistics.jpg)

### 好みの雰囲気に

ライト、ダーク、システム連動からテーマを選び、アクセント色を変更。言語と週の開始日も設定できます。

![ラベンダー色のダークテーマ](docs/images/dark.jpg)

_画像は現在のアプリと架空のサンプルデータを使用しています。透過とぼかしは OS とコンポジターに依存します。_

## はじめに

[GitHub Releases](https://github.com/kevinhuang001/pantodo/releases) で最新バージョンを開き、対応するインストーラーを選んでください。

| プラットフォーム        | インストーラー  |
| ----------------------- | --------------- |
| macOS · Apple Silicon   | `aarch64.dmg`   |
| macOS · Intel           | `x64.dmg`       |
| Windows · x64           | `.exe` / `.msi` |
| Ubuntu / Debian · x64   | `.deb`          |
| Fedora / openSUSE · x64 | `.rpm`          |
| その他の Linux · x64    | `.AppImage`     |

1. 作成画面で最初のタスクを書きます。
2. 必要なら予定や締切を設定します。
3. 今日、すべてのタスク、タイムテーブルで確認します。
4. 作業を始めるか、独自のビューを作って一日を整理します。

macOS ビルドはアドホック署名です。Linux の透過・ぼかしはデスクトップ環境に依存します。

## ローカル保存、必要なら同期

デスクトップ版は PC に、ブラウザー版は localStorage に保存します。設定の同期画面から既存の WebDAV ディレクトリに接続すると、タスク、プロジェクト、タグ、カスタムビューと作業記録を同期できます。競合時は内容を選択でき、実行中のタイマーと端末設定は同期しません。自動同期は任意で、ワークスペースのエクスポートにも対応します。

## 保存方法を選ぶ

設定 → 同期でローカルを選ぶと、この端末に保存しワークスペースをエクスポートできます。WebDAV を選ぶと接続設定と同期操作が表示されます。ローカルへ戻すと同期を停止し、接続情報は保持します。

![ローカル保存とエクスポート](docs/images/sync-local.jpg)

![WebDAV モードの接続設定](docs/images/sync-webdav.jpg)

## 集中時間を詳しく見る

ECharts で日別推移と累計、プロジェクト／タグの割合、時間帯ヒートマップ、タスクランキング、予定と実績、目標進捗を確認できます。ホバーで詳細を表示し、凡例で系列を切り替えます。統計コードはページを開いたときだけ読み込みます。

![集中時間の分布と目標](docs/images/statistics-detail.jpg)

起動ページ、予定の標準時間、パネルの高さ、集中画面の自動表示とカウントダウン、一日の目標、標準集計期間を設定できます。

![ワークスペース設定](docs/images/preferences.jpg)
