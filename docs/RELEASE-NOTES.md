# Pantodo 0.6.4

- 创建页详情随文本自动增高或收起，移除手动缩放手柄。
- 时间设置改为开始／结束／截止三行；日期和时刻分别点击弹出。未填写的结束选择器定位到开始时间，支持跨天设置。预估时长独立选择，不再显示“未设置”状态。
- 未完成待办点击勾选框先确认完成；完成后变暗并添加删除线，再次点击直接恢复未完成。
- 时间表日期选择器高亮整个可见周或月份；压缩日历弹层，去掉多余空白。
- 面板拖动保持原尺寸，移位不缩放文字；Todo 仍不可拖动。
- 删除视图级筛选字段及界面、旧的视图读取转换和自动补齐时间逻辑；筛选仅保存在面板上。
- 项目、视图、面板共用离线 Emoji Mart，支持分类、搜索和肤色选择。
- 统一窗口边缘圆角；垃圾箱放在侧栏滚动内容的末尾。
- 设置新增 8 种主色调，适配明暗主题并保存选择。

Installers are published only after checks, browser workflows and all desktop builds pass.
