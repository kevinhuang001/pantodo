# Pantodo 0.5.1

- 侧栏使用更厚的磨砂遮色和原生 Sidebar / Acrylic 材质，只保留轻微背景透光。
- 创建页的日期、项目和标签选择器重新设计为统一的轻量弹层；项目与标签支持搜索及键盘操作，已选内容直接显示在卡片上。
- 日期通过应用内日历选择，开始、结束和截止分开编辑，时分使用应用内选择菜单；移动开始时间保留计划时长。
- 时间表删除 Today 按钮；保留滑杆并支持触控板捏合、双指触摸、Ctrl／⌘ 滚轮缩放，缩放时保持手势下的时刻位置。
- 列表、画廊、看板、面板及日／周／月按钮增加本地化的悬停和键盘焦点提示。

Installers are published only after checks, browser workflows and all desktop builds pass.
