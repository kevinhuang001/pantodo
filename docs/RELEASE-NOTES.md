# Pantodo 0.6.6

- 创建和编辑使用开始时间＋持续时间，自动计算结束时间，支持跨日；创建页截止时间独立设置。
- 重做时间弹层：分区日期／时间选择、快捷和自定义时长、自动结束时间预览。
- 移除顶部重复标题和 breadcrumb 栏，保留视图排列／展示与设置操作。
- 时间表截止时间改为主色调旗标卡片，分开展示时间与任务名；列表补全状态、备注、项目、标签、起止时间与持续时间。
- macOS 窗口按钮使用红黄绿圆点和对应悬停符号；原生材质改为 UnderWindowBackground，降低侧栏叠加底色。
- Windows 使用 Acrylic 并降低材质色不透明度；Linux 保留半透明背景和 CSS 模糊（桌面模糊取决于窗口合成器）。

Installers are published only after checks, browser workflows and all desktop builds pass.
