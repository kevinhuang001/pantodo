# Pantodo 0.5.0

- View 支持列表、画廊、状态看板和组合面板，分别保存展示方式；切换时保留面板配置。
- 创建页重做为完整书写卡片，移除重复边框；内置 16 句中英日文随机文案，删去说明、提示和页脚。
- 标题导航与窗口控制合并为 44px 高度的一行。
- 面板使用鼠标、触摸或键盘拖动排序，刷新后保留位置；Todo 本身不可拖动。
- 根据原生平台显示 macOS 三色按钮；修复拖动区域遮挡按钮，增加八个窗口缩放边缘和角落。
- Project 只保留名称与图标，仅 Tag 使用颜色；日历按标签着色。
- 时间表只保留日、周、月，导航收成单行，缩放直接拖动滑杆。
- 编辑 View 只保留名称、图标和折叠筛选；模板与布局在面板工作区配置。
- 侧栏减淡遮色，使用原生 Liquid Glass Clear / Sidebar / Acrylic 材质。
- 删除旧分组渲染器、隐藏示例、原型迁移分支及失效文案，文档统一为当前实现。
- 修复 CI 中选择菜单焦点尚未就绪便执行按键的测试竞态。

Installers are published only after checks, browser workflows and all desktop builds pass.
